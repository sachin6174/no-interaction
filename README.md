# NoInteraction 🛡️ — Multi-Platform Anti-Gravity Prompt Approver

![NoInteraction Version](https://img.shields.io/badge/version-v1.4.0-cba6f7?style=flat-square)
![Platforms](https://img.shields.io/badge/platforms-macOS%20%7C%20Windows%20%7C%20Linux-89b4fa?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-a6e3a1?style=flat-square)

**NoInteraction** is an autonomous multi-platform agent observer and confirmation approval automation engine. It monitors AI coding assistants (Antigravity, VS Code, Cursor, Windsurf, Claude Code, Terminal sessions) and automatically approves confirmation dialogs, ticks consent checkboxes, and dispatches automated prompt testing queues.

## 🔥 Key Capabilities

1. **Auto-Click Approval Buttons**: Automatically clicks buttons labeled `Allow`, `Approve`, `Confirm`, `Proceed`, `Accept`, `Run Command`, etc.
2. **Auto-Tick Consent Checkboxes**: Selects options labeled `Remember`, `Trust`, `Don't ask again`, `Always allow`, etc.
3. **Prompt Queue Dispatch**: Automatically pastes sequential prompts into AI chat inputs when the agent is free.
4. **Loop Test Mode**: Repetitive stress-testing via continuous system auditing.
5. **Terminal Auto-Return**: Presses Return on attached terminal / PowerShell sessions when prompts appear.
6. **Code-Signed Executables**: Fully signed binaries for hassle-free installation.
